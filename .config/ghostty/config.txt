# NOTE: the real config is this .txt file; ~/.config/ghostty/config is a
# symlink to it. Ghostty's fixed config path has no extension, so macOS types
# it as public.data and `open_config` (cmd+,) ignores the public.plain-text
# editor default. Following the symlink to a .txt target routes cmd+, to the
# public.plain-text handler (MacVim). See tynet-omz setups/osx/rc.zsh.
